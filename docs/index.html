Fed 定價怎麼算
  • ZQ（30 天聯邦基金期貨）價格 = 100 − 該月 EFFR 平均。
  • 會議月份：月平均 =（會議前天數 × 舊利率 + 會議後天數 × 新利率）÷ 當月天數，解出會議後利率。
  • 會議後剩不到 7 天時改用下個月合約，因為整個月都是會議後利率，比較準。
  • 多次會議用接力：上一次會議後的利率當下一次的起點，第一次從當天 EFFR 開始。
  • 機率 = 隱含變動 ÷ 25bp，拆成最接近的兩檔結果。期貨只告訴我們平均預期，分佈形狀是假設；價格也含少量風險溢酬。
  • ZQ 報價來自 Yahoo Finance（非官方、有延遲），可以和 CME FedWatch 對照。

資料：U.S. Treasury Daily Par Yield Curve · New York Fed EFFR · CBOT ZQ via Yahoo Finance。每個交易日收盤後由 GitHub Actions 自動更新。
